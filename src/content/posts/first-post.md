> **Sample content.** This post exists only to show how prose is formatted on this site. Delete `src/content/posts/first-post.md` when you publish your own writing.

This is an ordinary paragraph. Most posts will be mostly paragraphs like this one: a few sentences, separated by blank lines, with nothing else around them. The text column is kept narrow on purpose so lines stay comfortable to read.

A second paragraph follows after a blank line in the Markdown file. You can add *emphasis*, **strong emphasis**, and [links to other pages](https://example.com) inline.

## A section heading

Use `##` for sections inside a post. The post title is already the page's main heading, so start sections at level two.

Lists work as you'd expect:

- An unordered item
- Another item
- A third item

Numbered lists too:

1. First
2. Second
3. Third

### A smaller heading

> A blockquote is useful for quoting another writer. Put a `>` at the start of the line.

A horizontal rule separates larger parts of a piece:

---

And that's all there is to a basic post: front matter at the top, Markdown below.
